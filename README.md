# CamSim — 真实相机物理模拟器

浏览器运行的相机模拟器，使用可计算的物理模型与实时 WebGL2 后期管线，还原曝光、对焦、白平衡、景深、运动模糊、噪点、闪光、防抖、包围曝光、HDR、胶片模拟/LUT 等真实相机逻辑。不是 CSS 滤镜页面，核心成像全部由可解释模型与自写 GLSL 后期链产生。

## 启动方式

需要 Node.js 20+（项目使用 pnpm 管理依赖）。

```bash
cd "Cam Sim"   # 进入项目目录（按你实际 clone 的路径调整）
# 安装依赖（若已完成可跳过）
pnpm install
# 开发模式
pnpm dev      # http://127.0.0.1:5173
# 生产构建
pnpm build
# 单元测试（70 项）
pnpm test
# 监视模式（开发时自动重跑）
pnpm test:watch
# 覆盖率报告（终端 + coverage/ HTML + lcov，带阈值校验）
pnpm test:coverage
```

> Windows 编辑器原子保存可能触发 Vite 原生监听 EBUSY，`vite.config.ts` 已启用 `server.watch.usePolling` 规避。

浏览器控制台会输出 `[相机自测] 49/49 通过`。关键调试入口：`window.__cameraEngine`（引擎）、`window.__cameraStore`（Zustand store）、`window.__cameraCapture()`（拍摄，含驱动/包围/HDR 编排）、`window.__cameraSelfTest()`（浏览器自测）。

## 部署到 GitHub Pages

本项目为 Vite 应用，需部署**构建后的 `dist/`**，而不是源码。已配置好自动部署，步骤：

1. 确认仓库为 Public，且默认分支为 `main`。
2. 在仓库页面进入 **Settings → Pages**，Build source 选择 **GitHub Actions**。
3. 将本仓库的改动推送到 `main`（含 `.github/workflows/deploy.yml`、`vite.config.ts` 的 `base: '/CamSim/'`、`public/.nojekyll`）。
4. Actions 会自动执行 `pnpm install → pnpm build → 部署`，完成后访问 `https://linan4268.github.io/CamSim/`。

> 若仓库改名，`vite.config.ts` 中的 `base: '/CamSim/'` 需同步改为新的仓库名，否则资源路径 404。本地 `pnpm dev` 不受该配置影响。

## 功能列表

### P0（已实现）
- **曝光三角**：快门 1/8000–30s，光圈 f/1.4–f/22（标准档/连续），ISO 100–25600（含扩展），实时 EV 与曝光补偿（−5~+5 EV，1/3 步进）
- **测光**：评价 / 中央重点 / 点测光，实时建议快门
- **实时取景**：直方图（RGB+亮度）、过曝/欠曝警告、曝光刻度
- **对焦**：手动距离、点击画面自动对焦（F 键中心对焦）、对焦峰值（P 键）、景深预览（D 键）
- **白平衡**：2000–10000K + 色调偏移，预设（日光/阴天/白炽灯/荧光灯/自定义）
- **景深与运动模糊**：基于 CoC 与深度图的后期景深、基于运动掩码+快门时间的拖影
- **成像后期**：曝光→WB→高光滚降→景深→运动模糊→色差→暗角→噪点→锐化/衍射→色调映射
- **拍摄/回放**：生成 JPEG 照片、EXIF 风格参数、对比查看、下载
- **交互**：方向键调参、空格拍摄、拖拽旋转/滚轮变焦、重置相机/场景
- **3D 场景**：近中远景、灰卡、彩色球、高光板、运动物体，主光强度/色温/方向/相机倾角可调

### P1（已实现）
- **快门类型**：机械快门（无果冻） / 电子快门（按读出时间 `1/(2·t_readout)` 计算果冻强度，逐行水平剪切）
- **驱动模式**：单张 / 连拍（3/5/10 帧，120ms 间隔）/ 定时（2/5/10s 倒计时）
- **包围曝光**：对称 EV 序列（3/5/7 张，步进 1–3 EV），逐帧独立曝光参数
- **多曝光 HDR**：包围帧线性解码 → 中调高斯权重逐通道融合 → 生成 HDR 照片（RAW 线性 readback）
- **闪光灯**：开/关、前帘/后帘同步、闪光功率 EV（距离平方反比 + ISO/光圈耦合）、同步速度提示
- **防抖（IS）**：折算手持安全快门（`t / 2^stops`，4 档补偿），渲染层抖动幅度降低
- **拍摄辅助**：斑马纹（阈值 0.95，45° 斜纹警告）、构图辅助线、电子水平仪（跟随场景倾角）
- **色彩风格**：5 种胶片模拟（STANDARD / PORTRAIT / LANDSCAPE / MONO / LOG，矩阵+LGG+对比度+饱和度）、内置与自定义 `.cube` 3D LUT（三线性插值）
- **ND 滤镜**：0–10 档，等效快门 `t·2^ND`

### P2（已实现）
- **传感器**：全画幅 / APS-C / M4/3，切换联动等效焦距、视角、景深、衍射、噪点缩放、裁切系数
- **镜头**：广角 14–35mm / 标准 24–85mm / 长焦 70–200mm，切换自动把焦距钳制到镜头范围
- **文件格式**：JPEG（机内处理） / RAW（线性 HDR 数据 + 机内预览），EXIF 标注格式与线性数据状态
- **预设系统**：导出/导入 JSON 预设（serializePreset / deserializePreset），一键载入全部参数
- **水印导出**：回放页勾选水印，canvas 合成 EXIF 三行信息后导出 JPEG/PNG
- **包围序列条**：回放页显示整组包围照片与 EV 标签，可点选对比；HDR 合成图单独标记

## 物理模拟 vs 近似效果（诚实标注）

### 真实物理/可解释模型
- EV 与曝光增益（严格按光圈/快门/ISO 的 2 的幂关系）
- 超焦距/景深/弥散圆（薄透镜模型，c 随传感器变化：全画幅 0.03mm / APS-C 0.02mm / M4/3 0.015mm）
- 色温→RGB 增益（CIE 近似色温表插值，取倒数归一化）
- 散粒噪声 ∝√信号、读出噪声 ∝√ISO（按传感器缩放）
- ACES 色调映射 + 高光肩部滚降
- 衍射斑 `2.44λN`（按裁切系数折算）
- 运动模糊长度 ∝ 快门时间 × 屏幕速度
- 暗角/桶形畸变随光圈/焦距变化
- ND 透射率 `2^(−ND)`、等效快门 `t·2^ND`
- 闪光曝光 `P − 2·log₂(d) + log₂(ISO/100) − 2·log₂(N)`（距离平方反比）
- 防抖安全快门 `t/2^stops`、果冻强度 `clamp(1−t/(2·t_readout),0,1)`
- 包围 EV 对称序列、HDR 中调高斯加权融合 `data/2^EV`
- 胶片模拟矩阵乘法 + LGG（lift/gamma/gain）+ 对比度/饱和度，`.cube` LUT 三线性插值
- 传感器裁切系数联动视角 `f_eff = f·crop`、衍射、噪点、景深

### 近似 / 风格化（非严格物理）
- **景深模糊**：12-tap 黄金角采样近似真实镜头 PSF，非严格卷积
- **运动模糊**：12-tap 线性卷积，仅作用于运动物体掩码（简化相机/全局运动）
- **果冻效应**：逐行水平剪切近似 CMOS 卷帘读出，未建模逐行曝光时刻的透视变化
- **闪光**：作为曝光增益加权叠加，未模拟闪光与环境光的光质/色温混合与阴影
- **色差**：屏幕径向偏移模拟横向色差，未按波长色散积分
- **噪点**：伪随机分布，未模拟拜耳阵列与去马赛克
- **HDR 融合**：中调高斯权重启发式，非严格跟随传感器响应曲线的 Mertens 算法
- **胶片模拟/LUT**：风格化矩阵与查表，非真实胶片光谱响应
- **测光亮度**：线性场景亮度加权，非 CIE 1931 标准观察者完整模型
- **校准常数**：曝光增益乘 1000 将物理 EV 映射到 HDR 场景亮度，属系统标定
- **HDR 环境**：方向光+环境光+高亮板近似，未加载真实 HDRI

## 已知限制
- 仅 WebGL2；WebGPU 后端接口预留但未实现
- 移动端可操作核心参数但取景器尺寸受限
- 单 693KB JS chunk（Vite 提示，非错误），可后续代码分割
- 点击对焦使用屏幕 NDC 射线，边缘点可能命中背景（返回较大距离）
- 连拍为定时轮询拍摄，非真正高速缓存写入（受浏览器渲染节奏限制）
- RAW 为线性 readback + 机内预览，非传感器原始拜耳数据
